# Diccionario de datos — SoporteYa

## EMPRESAS

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---:|---|---|
| id_empresa | NUMBER GENERATED BY DEFAULT AS IDENTITY | No | PK | Identificador de la empresa |
| rut | VARCHAR2(12) | No | UNIQUE | RUT de la empresa |
| razon_social | VARCHAR2(120) | No |  | Nombre legal |
| plan | VARCHAR2(10) | No | CHECK | `BASICO` o `PREMIUM` |
| activo | NUMBER(1) | No | CHECK | 1 activa, 0 inactiva |

## CATEGORIAS_TICKET

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---:|---|---|
| id_categoria | NUMBER GENERATED BY DEFAULT AS IDENTITY | No | PK | Identificador de categoría |
| nombre | VARCHAR2(80) | No | UNIQUE | Nombre de la categoría |
| horas_sla | NUMBER(5) | No | CHECK > 0 | Horas máximas para resolver |
| activo | NUMBER(1) | No | CHECK | 1 activa, 0 inactiva |

## TECNICOS

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---:|---|---|
| id_tecnico | NUMBER GENERATED BY DEFAULT AS IDENTITY | No | PK | Identificador del técnico |
| rut | VARCHAR2(12) | No | UNIQUE | RUT del técnico |
| nombre | VARCHAR2(120) | No |  | Nombre completo |
| email | VARCHAR2(150) | No | UNIQUE | Correo del técnico |
| activo | NUMBER(1) | No | CHECK | 1 activo, 0 inactivo |

## TICKETS

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---:|---|---|
| id_ticket | NUMBER GENERATED BY DEFAULT AS IDENTITY | No | PK | Identificador del ticket |
| id_empresa | NUMBER | No | FK | Empresa solicitante |
| id_categoria | NUMBER | No | FK | Categoría y SLA |
| id_tecnico | NUMBER | Sí | FK | Técnico asignado |
| titulo | VARCHAR2(150) | No |  | Resumen del problema |
| descripcion | CLOB | No |  | Descripción completa |
| prioridad | VARCHAR2(10) | No | CHECK | `BAJA`, `MEDIA`, `ALTA` o `CRITICA` |
| fecha_creacion | TIMESTAMP WITH TIME ZONE | No | DEFAULT | Fecha UTC de creación |
| fecha_cierre | TIMESTAMP WITH TIME ZONE | Sí |  | Fecha UTC de cierre |
| estado | VARCHAR2(15) | No | CHECK | Estado del flujo del ticket |

## COMENTARIOS_TICKET

| Columna | Tipo Oracle | Nulo | Restricción | Descripción |
|---|---|---:|---|---|
| id_comentario | NUMBER GENERATED BY DEFAULT AS IDENTITY | No | UNIQUE | Identificador técnico usado por Django Admin |
| id_ticket | NUMBER | No | PK, FK | Ticket comentado |
| numero | NUMBER(6) | No | PK, CHECK > 0 | Secuencia del comentario dentro del ticket |
| fecha | TIMESTAMP WITH TIME ZONE | No | DEFAULT | Fecha UTC del comentario |
| autor | VARCHAR2(120) | No |  | Autor visible del comentario |
| texto | CLOB | No |  | Contenido del comentario |
